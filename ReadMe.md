# 🐾 반려동물 살균소독스프레이 사전 런칭 랜딩 페이지

> 제품 정식 출시 전 핵심 고객 확보를 위한 **Pre-launch Marketing Landing Page** 프로젝트  
> AI 협업(Vibe Coding)을 활용해 단기간 내 구축한 고전환(High Conversion) 마케팅 웹사이트

---

## 📌 About Project

본 프로젝트는 반려동물 살균소독스프레이 출시 전, 초기 잠재 고객을 확보하고 시장 반응을 검증하기 위해 제작된 **사전 런칭 랜딩 페이지**입니다.

제품의 핵심 USP(안전성·살균력·친환경성)를 명확하게 전달하고, 사용자의 행동을 자연스럽게 유도하는 **전환 중심 UI/UX 및 CTA 구조**를 설계했습니다.

또한 **비개발자 창업자가 AI 협업(Vibe Coding)을 활용하여 기획 → 퍼블리싱 → 배포까지 직접 수행한 실전 마케팅 프로젝트**입니다.

---

## ✨ Key Features

- 사전 고객 확보(Lead Capture) 구조 설계
- 전환 중심 CTA 및 랜딩 페이지 UX
- 카운트다운 기반 얼리버드 마케팅 장치
- 모바일 최적화 반응형 UI/UX
- 외부 폼(Google Forms/API) 연동 구조
- GitHub Pages 기반 정적 배포
